## T6. Decision

ATDR v3.29 upgrades the read-only SOC Assistant from evidence summarization toward professional triage guidance. ATDR remains FastAPI + React + SQLAlchemy/Alembic, with SQLite for local development, optional PostgreSQL validation later, local JWT/RBAC, simulated response, and ML decision support only. Real-source hardware forwarding, production detection accuracy, real MFU IAM login, Google callback login, token introspection, SMTP delivery, verified-email enforcement, detection score threshold changes, ML activation, real firewall blocking, automatic response, external LLM use, raw-log context sharing, action execution through chat, automatic assistant tuning, feedback status lifecycle, persisted investigation notebooks/incidents, true async workers, queue-backed retries, durable cancellation, automatic retention, dedicated run/job detail pages, and run-history archival remain future work; production readiness is still not claimed.
