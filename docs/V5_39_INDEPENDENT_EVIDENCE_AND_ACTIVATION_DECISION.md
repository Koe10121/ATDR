2. Claim **Detection Blind Review** and complete all 40 protected rows.
3. Claim **Assistant Acceptance** and complete all eight protected answers.
4. Close each workspace only after its validation reports no missing or
   invalid decisions.
5. Confirm the aggregate readiness state:

```powershell
.\.venv\Scripts\python.exe -m atdr.scripts.run_v539_independent_evidence_decision --preflight-only --pretty
```

The reviewer must be a real person. Do not enter AI, rule, model, Codex,

## Single Frozen Evaluation

Only after both workspaces report complete, closed, and contract-valid, run:

```powershell
.\.venv\Scripts\python.exe -m atdr.scripts.run_v539_independent_evidence_decision `
  --execute `
  --confirm FROZEN_V539_EVALUATION `
  --pretty
```

The evaluator creates an exclusive filesystem claim before calling the v5.36
audit. Concurrent processes cannot both evaluate. A completed, failed,
or interrupted claim cannot be silently rerun. A completed invocation returns
its stored sanitized result on later calls rather than recalculating metrics.
The private claim/freeze state and optional reports remain under ignored
`ml_baseline_reviews/`.

This command does not train, tune, activate, promote, import labels, call an
external LLM, create detection runs, alter alerts, or create response actions.
Even passing measurements can only make a candidate eligible for a separate
manual activation review; they do not activate it.

## Public And Private Boundaries

The API, CLI status, and dashboard may expose only aggregate counts, closure
state, lifecycle, safe blockers, and sanitized frozen metrics after the single
evaluation. They never expose:

- raw logs, IP addresses, filesystem paths, review tokens, or fingerprints;
- hidden model predictions or scores before review closure;
- reviewer identity;
- pack or decision digests; or
- API keys, provider payloads, or other secrets.

Digests exist only in the ignored private freeze record so later pack or
decision changes fail closed.
